# Rakesh Singh

AI backend engineer building agent guardrails: what an agent may do, what it costs, and whether its answers are grounded.

- [**opfence**](https://github.com/rakeshnitb23/opfence): each coding-agent request runs, asks you, or is blocked. 7,057 rules, including 29 MCP servers, replayed from a recorded request. Early, and not ready for a production account. [How a decision is made](https://github.com/rakeshnitb23/opfence/blob/main/docs/ARCHITECTURE.md).
- [**toolism**](https://github.com/rakeshnitb23/toolism): toolslim cuts tokens spent re-sending tool schemas and tests that the same calls still work. 37.4% fewer tokens across 159 tools from 13 MCP servers (73% on Notion).
- [**groundeddocs**](https://github.com/rakeshnitb23/groundeddocs): document Q&A that abstains unless every citation matches a retrieved chunk. [Citations get checked, not trusted](https://portfolio-sage-gamma-15.vercel.app/writing/citations-get-checked-not-trusted).
- [**fuel-route-planner**](https://github.com/rakeshnitb23/fuel-route-planner): where to buy fuel on a US road trip. New York to Los Angeles on the [live demo](https://fuel.lazymonk.si): 2,800.6 miles, 17 stops, $846.76.

Now: Opfence's catalog and proxy are in progress. It does not guard a production account yet.
